First public version of the AoE:DE Mod Manager (build 7).

**Download** `AoEDE_ModManager.exe` below, put it in its own folder and double-click it. See the README for details.

**Online play:** visual mods can be used online. Data mods (files in `Data\`, such as `empires.dat`) will cause
the game to crash in online play: untick them and press Apply before playing online.

- Add mods from `.zip` files, tick them, apply them, restore the original game files at any time.
- Load order with Move up / down, and a conflicts list.
- Remove mods (to the Recycle Bin), Get Mods (official mod website), Launch Game.
- Locked while the game is running.

Windows may show "Windows protected your PC" because the program is not code-signed: **More info > Run anyway**.
